# Claude Instructions

## Documentation Maintenance

As changes are made to the codebase, keep the following files up-to-date:

- **spec/** — The specification, one file per functional area (index: `spec/README.md`). Reflect any change to observable behavior, requirements or design decisions in the section that owns it, following the specification-stewardship skill.
- **PROJECT_PLAN.md** — Reflect any changes to planned features, completed milestones, architecture decisions, or shifts in scope.
- **README.md** — Reflect any changes to build instructions, dependencies, project structure, usage examples, or high-level descriptions.
- **AGENT_BOOTSTRAP.md** — The starting point for an agent new to the code. Reflect any changes to the source map, the build and verification workflow, or the working rules.
